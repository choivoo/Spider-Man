# Reference images

The three images that define the look of the project. They are **design references**, not textures — nothing is copied pixel-for-pixel.

| File | Used for |
|---|---|
| `civilian-fullbody.png` | Civilian form: slim adult proportions (≈7.6 heads incl. hair), curly swept hair silhouette, black open blazer / black tee / slim black trousers / black derby shoes, hands-in-pockets stance. |
| `spider-suit-turnaround.png` | Suit pattern & colour layout: front / ¾ / back / side. Red arms and boots, black legs, gold trim, chest spider, back emblem. |
| `nanotech-iron-spider.png` | Materials (metallic red, navy-black, brushed gold, cyan glow) and the four mechanical spider arms. |

`scripts/analyze-reference.py` extracts the measurements quoted in `docs/MODELING_GUIDE.md`.
